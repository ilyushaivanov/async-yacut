# YaCut — сервис сокращения ссылок

Учебный проект сервиса для укорачивания длинных URL и пакетной загрузки файлов на Яндекс Диск с выдачей коротких ссылок на скачивание.

## Назначение

Проект решает две задачи:
1. **Сокращение длинных ссылок** — пользователь получает короткую ссылку вида `yacut.ru/12e07d`, которую удобно передавать в чатах, письмах и интерфейсах. Короткая ссылка может быть сгенерирована автоматически или задана пользователем.
2. **Пакетная загрузка файлов и ссылки на скачивание** — загрузка сразу нескольких файлов на Яндекс Диск и выдача пользователю набора коротких ссылок для скачивания. Это удобно для передачи файлов без вложений (например, в поддержке, HR, маркетинге).

## Стек технологий

- Python 3.9+
- Flask (веб‑приложение)
- PostgreSQL + SQLAlchemy (ORM) для хранения пар «длинная/короткая ссылка», статистики и метаданных файлов
- Docker, Docker Compose (воспроизводимое окружение)
- Яндекс Диск API (загрузка файлов, получение публичных ссылок)
- pytest (тестирование основных сценариев)

## Мой вклад

- спроектировал схему БД под хранение ссылок, статистики переходов и метаданных загруженных файлов;
- реализовал REST‑эндпоинты для создания коротких ссылок (с автогенерацией и кастомным ключом);
- интегрировал Яндекс Диск API для пакетной загрузки и получения публичных ссылок;
- настроил сбор базовой аналитики (количество переходов, дата, IP);
- упаковал проект в Docker Compose (веб, БД, опционально — сервисы для тестов);
- написал тесты на основные сценарии (pytest): создание ссылки, редирект, валидация ключей, обработка ошибок API.

### Как запустить проект Yacut:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone 
```

```
cd yacut
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Создать в директории проекта файл .env с четыремя переменными окружения:

```
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DB=sqlite:///db.sqlite3
```

Создать базу данных и применить миграции:

```
flask db upgrade
```

Запустить проект:

```
flask run
```
